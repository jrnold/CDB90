# CDB90 codebook

Generated by `scripts/codebook.py` from the table schemas; do not edit by hand.
The original documentation of CDB90 is `src-data/M000121/README.TXT`; the DTIC record
of the database (AD1038724) is `src-data/docs/AD1038724.pdf`, with its OCR text in
`AD1038724.md`.

## Flat tables

For analysis. Each is `data/flat/<name>.csv` and `data/flat/<name>.parquet`; the CSVs are
described by `datapackage.json`. Missing values are empty.

### `narratives`

One row per battle that has a narrative (610 rows): the narrative, its significance and its sources, parsed from the OCR text of CAA-SR-84-6 (the HERO volumes) and of the 1988 report "New Engagement Data for the Breakpoints Data Base". The first 600 battles of CDB90 are described in the volumes; 585 of them have a narrative in the OCR text, and so does battle 601. The 1988 report has the 24 battles 602 to 625. The other 15 of the first 600 are battles of the 1967 and 1973 Arab-Israeli wars that the volumes list only in a table of contents, and a few others; 626 to 660 have no narrative. The sources are full citations, one per line.

| Column | Type | Description |
|---|---|---|
| `isqno` | integer | battle sequence (line or serial) number |
| `name` | string | name of battle |
| `hero_volume` | integer | Volume of CAA-SR-84-6 (II to VI) the narrative is in; empty for the 1988 report. |
| `hero_title` | string | The heading of the narrative, with the battle's name and dates as printed. |
| `narrative` | string | The narrative, in paragraphs separated by a blank line. |
| `significance` | string | The "Significance" paragraph of the narrative. |
| `sources` | string | The sources of the narrative, one full citation per line. The volumes give codes such as `M.19` or `B.11.1`; each is replaced by the entry of the bibliography at the end of the volumes, and `(vol. 1)` after a citation is the volume of a multi-volume work. The 1988 report lists its sources by operation, so the engagements of an operation share one list. |
| `document` | string | The document the narrative is from: a volume of CAA-SR-84-6 or the 1988 report "New Engagement Data for the Breakpoints Data Base" (AD-A201404). |

## Relational tables

The tables loaded into `cdb90.sqlite3`; one CSV per table in `data/relational/`.
`isqno` is the battle's sequence number in CDB90 and links the tables.

### `battle_actors`

The actors associated with belligerents in each battle. Each side of a battle (belligerent) can include forces from one or more actors, which can be states or non-states. This table lists those actors. The names of the actors don't correspond to any particular list of state or non-state actors since no list that I am aware of goes back to the 17th century. However, an effort is made to use the COW names of states for state actors in battles after 1816.

| Column | Type | Description |
|---|---|---|
| `isqno` | integer |  |
| `attacker` | boolean | Was actor on the attacking side? |
| `n` | integer | Number of actor, for battle/belligerent combinations. |
| `actor` | string | Name of actor |

### `battle_coordinates`

Coordinates of battles, from Wikidata (CC0). Each battle gets the point of its most specific item that has coordinates, and `precision` says what kind of item that is, so the point of a campaign can be told from that of a battlefield. The points are not checked against the CDB90 location text. Built by `scripts/coordinates.py` from `battle_links`, plus place lookups in `src-data/local/coordinates_places.csv`.

| Column | Type | Description |
|---|---|---|
| `isqno` | integer | Battle sequence number. |
| `latitude` | number | Latitude (WGS 84, decimal degrees). |
| `longitude` | number | Longitude (WGS 84, decimal degrees). |
| `wikidata_id` | string | Wikidata item the point comes from. |
| `precision` | string | What the point is: `battle` (the battle's own item), `place` (the place where the action took place or that it is named after), `area` (a town, commune or district the HERO narrative puts the action in or beside, when the action itself has no item), `campaign` (an operation or campaign it was part of), `region` (a larger area) or `war`. The points are ordered from most to least specific. |
