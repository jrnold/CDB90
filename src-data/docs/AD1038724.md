    <td colspan="5"><b>14. ABSTRACT</b><br />Abstract:( U ) File characteristics: Datafiles (11 files); LOTUS-readable format, plus one ASCII file. Physical description: 2 computer disk; 3 1/2 in., 1.2m. System requirements: IBM PC compatible; MS-DOS 3.21; LOTUS 1-2-3 or QUATTRO PRO Version 3.00. A database of over 600 battles that were fought between 1600AD and 1973AD. Descriptive data include battle name, date, and location; the strengths and losses on each side; identification of the victor; temporal duration of the battle; and selected environmental and tactical environment descriptors (such as type of fortifications, type of tactical scheme, weather conditions, width of front, etc.).</td>
